# 加班手记 1.3.0 升级说明

本次完成优化表第1—9项及第16项。保留离线、本机数据、中英文切换、旧版记录格式与原签名；没有加入加班费估算、调休台账或计时打卡。

## 功能与使用

| 项目 | 使用方式与口径 |
| --- | --- |
| 跨月分配 | 数据页打开“跨午夜按天拆分”。默认关闭，沿用旧版归开始日期的方式。 |
| 休息分配 | 按午夜前后总时长比例分配整数休息分钟，余数归次日；分配后总休息和净分钟数守恒。 |
| 结算周期 | 设置每期起始日1—31；选择26日时，“2026年11月”为10月26日至11月25日。短月取月末，日期范围最早为2000年1月1日。 |
| 向下取整 | 默认精确到分钟，可选5、15、30分钟。每条记录先取整，再按净时长比例分配计入分钟，余数归次日。原始起止和休息始终保留。 |
| 明细核算 | 录入或编辑页面显示总时长、休息、原始净时长、计入时长及每日分配。 |
| 周期核对与锁定 | 首页“核对结算周期”，人工核对后锁定。界面合计需与本机数据层合计一致才允许操作。锁定阻止涉及该周期的新增、改动、删除、回收站恢复和导入。跨周期记录任一归属周期锁定时整条记录均受保护。 |
| 修改规则 | 存在锁定周期时不能改变结算日、拆分或取整。外观仍可调整。 |
| 漏记提醒 | 在数据页选择星期和本地时间。当天已有开始日期为今天的记录则跳过。通知提供“30分钟后提醒”。启用时才请求通知权限。 |
| 恢复副本 | 升级、导入、批量补录、改变计算规则前自动保存，最多5份。恢复前再次保存当前状态；恢复替换记录、模板、回收站、规则、语言、锁定及提醒设置。 |
| 导入冲突 | 同编号可跳过、替换或保留两条。完全相同记录始终跳过；保留两条也不得造成时间重叠。预览后提交时再次检查，失败回滚。备份内部重复编号会拒绝整次导入。 |
| 备份迁移 | 支持旧版1、2和新版3的备份。合并导入默认保留本机设置；可选择恢复外观与计算规则。合并后的记录不自动继承备份中的周期锁定和提醒设置，须重新核对及启用提醒。 |
| 报表 | 按当前结算周期导出，包含归属日期、原记录日期、总分钟、休息、原始净分钟、计入分钟、分类及合计。跨日原记录可能有两行，记录数按原编号去重。 |
| 图表明细 | 月图使用结算周期；周图按自然周、年图按自然年。点击后的明细日期、类别和分钟合计与当前可见图表一致。自然月日历有独立标注。 |
| 备份提示 | 超过7天未导出，或尚无备份记录时，在数据页提示；有记录时首页也显示导出入口。属于打开应用时的提示。 |

## 重要边界

- 工时按手工填写的钟面时间计算，使用固定日期算术；不根据当前手机时区重算，不自动补偿夏令时切换造成的实际经过时长差异。记录夏令时切换当晚的实际出勤时，需要自己核对钟面时长。
- 提醒采用系统非精确定时，不保证准点，省电或厂商后台限制可能延迟；强行停止后需重新打开应用。Android 13及以上须允许系统通知，应用会显示通知是否可用。
- 本机恢复副本位于应用私有目录，卸载、清除应用数据或遗失设备都会丢失。独立导出的备份才适合用于迁移或卸载后恢复；请存到本机独立文件。
- 本机恢复会替换当前数据，界面有明确确认；普通导入则按所选方式合并。
- 继续禁止联网，关闭系统自动云备份。新增权限只有通知和开机重排提醒。
- 图表和报表中的“工作日、休息日、节假日”由用户手选，不作为法定加班费结论。

## 安装

1. 在旧版“数据”页导出完整备份到手机本地。
2. 打开 `overtime-notes-1.3.0.apk`，选择更新/安装。不要先卸载旧版。
3. 检查原记录、语言和总工时。默认仍是自然月、归开始日期、精确到分钟。
4. 如需新规则，在“数据→工时与结算规则”设置。首页月份代表结算期的结束月份。

安装包沿用旧版签名。签名私钥不属于开源源码或下载包内容。
