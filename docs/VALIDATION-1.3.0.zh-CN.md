## 测试方法

```bash
npm ci
npm test
npx playwright install chromium
npm run test:ui
python3 build.py --release
python3 tests/build_android_tests.py
python3 tests/run_android_verification.py
```

Java对照测试：先运行`npm test`生成`build/settlement-vectors.tsv`，用构建脚本下载的编译器编译`tests/SettlementTest.java`，再执行`java -cp build/test-classes:build/classes SettlementTest build/settlement-vectors.tsv`。

构建和原生测试使用私下保存的原签名凭据；源码和公开下载中不含私钥。原生测试需要本机模拟器工具及Android 9 x86_64镜像，路径见测试脚本说明。浏览器可以通过`PLAYWRIGHT_CHROMIUM_EXECUTABLE`指定兼容的本机可执行文件。
