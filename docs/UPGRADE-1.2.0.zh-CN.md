# 加班手记 1.2.0 更新说明

日期：2026-10-24。适用 Android 8.0 及以上。
APK（Android Package，安卓安装包）保持包名 cn.lan.overtime 与旧版发布签名，版本代码提升为3。

## 安装

在旧版“数据”页先导出完整备份，然后打开新版安装包直接覆盖安装。不要先卸载旧版。升级不会重写已有记录的日期、时间、备注或类型。

## 本轮功能

1. 趋势图：周、月、年切换；柱状图与折线图；前后周期翻页；图表可展开，支持手机横屏。
2. 图表交互：点击数据点查看精确时长并筛选明细；点击分类图例隐藏或显示分类。关闭动画或系统开启减少动态效果后，不播放图表过渡动画。
3. 月度卡片：净时长、加班天数、次数、平均每次时长、最长单次，以及与上月同期的时长差。当前月只比较到今天，历史月份比较整月，上月截止日期最多取到月末。
4. 日历热力图：颜色深浅对应每日净时长，点击已有记录日期查看明细，点击空日期补录；跨午夜记录显示圆点。
5. 分类环形图：显示三种类别的分钟、占比，点击分类筛选明细。
6. 常用模板：最多30个，保存时段、休息、类型、备注；使用模板保留当前日期。支持使用、改名与删除。
7. 复制与补录：复制上次时段；编辑时复制成新记录；一次最多选择62个日期，预览冲突，按日期报告保存结果。
8. 日期范围、类别与备注联合筛选，显示筛选合计；可跨月查看或回到本月。
9. 回收站：删除后可立即撤销，记录保留30天，到期后再次读取回收站时清除；恢复会重新检查时间重叠。彻底删除前再次确认。
10. 备份：只有完整备份文件成功保存后才更新备份时间。导入先预览，不写入数据；确认后再合并并重新检查冲突。支持旧版备份。
11. 升级：保留旧数据库和语言设置；沿用原签名，支持覆盖安装。
12. 外观：跟随系统、浅色、深色、柔和四种主题；文字跟随系统字体比例或额外加大；动画可关闭。中英文界面完整保留。

## 备份与数据规则

JSON（JavaScript Object Notation，结构化数据格式）完整备份升级为版本2，包含全部月份的有效记录、未过期回收站、模板、显示设置和已选择的语言。新版可导入版本1、2备份；旧版1.1.0不能导入版本2备份。

导入最多64MB，有效记录与回收站各最多10000条。整个文件通过格式校验后才显示预览，确认时在数据库事务中合并。已有编号（包括回收站中的编号）优先保留，重叠记录跳过；模板按编号合并，超过30个的部分跳过。回收站过期副本跳过。显示设置与语言默认不覆盖，可在预览中选择恢复。

CSV（Comma-Separated Values，逗号分隔值）表格导出仍包含全部月份的有效记录，用于查看而非恢复。备份和表格为明文，只应保存到你选择的本地位置。应用不自动生成外部备份、不联网、不上传数据。

跨午夜记录仍全部计入开始日期所在月份；休息时间填写总分钟。类别由使用者选择，不自动判断国家节假日，不计算工资。周趋势从周一开始。图表隐藏分类仅影响图表，明细仍显示所选日期范围中的全部分类。

## 本轮范围

本轮完成优化表第1—12项。项目标签、开始/结束计时、本地提醒、月度/年度报告导出、自设时长提醒线、加班费计算暂未加入。
