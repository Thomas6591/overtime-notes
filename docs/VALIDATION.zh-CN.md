## 复现

```sh
npm ci
npm test
npx playwright install --with-deps chromium
npm run test:ui
```

浏览器检查可用 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指定浏览器。浏览器测试使用模拟桥接层，不能单独证明安卓数据库持久化。

原生测试源码位于 tests/android。使用构建正式安装包的同一组安全签名环境变量运行 `python3 tests/build_android_tests.py`，再运行 `python3 tests/run_android_verification.py`。后者需要本机安卓模拟器、平台工具与API 28 x86_64系统镜像；可以通过 OVERTIME_TEST_SDK、OVERTIME_TEST_IMAGE 指定路径。该脚本只应用于专用测试模拟器，会卸载测试应用并重新准备旧版升级样本，不应连接使用者的真实手机。

## 验证边界

- 尚未在实体手机或所有品牌/安卓版本上验证。
- 安卓系统文件选择器中的实际导出写入、手动取消、第三方文件管理器差异，仍需目标手机验证；浏览器测试验证按钮与回调，原生数据库测试验证备份解析和合并。
- 日期/时间选择器、桌面名称及系统文件选择器跟随手机系统语言。
- 回收站依赖设备日期，到期记录在再次访问本地数据时清除；应用关闭时不运行后台清理服务。
- 统计使用填写的钟表时间，不调整时区和夏令时；跨月记录仍全部归入开始日期所在月份。
