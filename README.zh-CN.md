# 加班手记 / Overtime Notes

[English](README.md) · 简体中文

MIT 许可证开源的离线安卓加班记录应用，支持中英文即时切换。

适用：Android 8.0及以上。应用包名：cn.lan.overtime。
APK（Android Package，安卓安装包）内已包含全部代码和界面资源，无须服务器。

## 安装与使用

1. 从 [downloads/overtime-notes-1.1.0.apk](downloads/overtime-notes-1.1.0.apk) 下载正式安装包到安卓手机，用文件管理器打开。
2. 若系统要求，临时允许该文件管理器“安装未知应用”，再继续安装。
3. 打开“加班手记”，点“记一笔”，填写日期、开始结束时间、休息分钟和类型，保存。
4. 跨午夜时勾选“结束时间在次日”。同一日期可以录入多段时间，但时间段不能重叠。
5. 在主页面切换月份，查看净加班小时、精确分钟、加班天数和每日柱状图。点击明细可编辑或删除。

净加班分钟＝结束时间－开始时间－休息分钟。单条最多24小时。按填写的钟表时间计算，不自动修正夏令时或时区变化。跨月记录全部归入开始日期所在月份，休息时间只能填写总分钟，不能指定其在时间段中的具体位置。

工作日/休息日/节假日由你手动选择，不根据周末或国家日历推断。此版本不计算工资。

## 中英文切换

- 右上角“EN / 中文”按钮可立即切换，也可在“数据 / Data”页面点击“界面语言 / App language”。
- 首次运行跟随手机语言：中文系统默认中文，其他语言默认英文；手动选择后在应用私有数据库中保存，重启仍使用该选择。
- 应用页面、按钮、日期与星期标签、类型名称、错误信息、确认窗口和CSV表头随语言切换。你填写的备注保留原文。
- 为兼容1.0版本的数据库和备份，内部类型标识和JSON备份格式保持原样，仅在界面和CSV中翻译显示。
- 桌面启动器中的应用名称跟随系统语言，英文名称为 Overtime Notes。安卓文件选择器、日期/时间选择器等系统界面的语言由手机系统决定。
- 沿用旧版包名和签名，versionCode由1提升至2。请先导出备份，再直接覆盖安装新版，不要先卸载旧版。

## 数据与备份

- 无联网权限、无账号、无广告、无统计服务或远程资源。
- SQLite（嵌入式关系型数据库）的文件保存在手机应用私有的 noBackupFilesDir 目录；系统自动备份关闭，并配置排除云备份及换机迁移。
- “数据→导出完整备份”：保存全部月份的 JSON（JavaScript Object Notation，结构化数据文件）备份，可用于恢复。
- “数据→导出表格”：保存全部月份的 CSV（Comma-Separated Values，逗号分隔值）文件，可使用 Excel 打开；此表格不能导入恢复。
- “数据→导入备份”：仅接受本应用导出的原始 JSON 文件，合并导入。同编号记录无论内容是否相同均跳过，手机现有版本优先；时间重叠的记录也会跳过。结果会报告新增与跳过数量。
- 备份最多8MB、10000条。格式错误时取消导入，原有数据保留。
- 文件选择器请选择“下载”或手机内部存储，不要选择第三方网盘。应用没有自动导出、自动云同步或云端恢复。
- 卸载、清除应用数据、手机丢失或更换手机会丢失应用内记录；请提前导出备份。备份文件是明文，请自行保管。
- 手机输入法、手机厂商系统和用户自行安装的同步软件不属于本应用控制范围。无需任何敏感系统权限。

## 开发与更新

locales.json 是中英文翻译的唯一编辑来源；scripts/generate_locales.py 生成浏览器使用的translations.js，build.py会自动调用。翻译使用纯本地文件，不调用在线翻译服务。

app/src/main 是完整源码，界面为内置页面，Android 原生层负责数据库和系统文件选择器。

Linux 环境准备 Java 17（包含 keytool）和 Python 3，然后执行：

```sh
python3 build.py
```

首次编译会下载并校验安卓平台、构建工具和编译器。开发签名密钥在本机 `.local-signing/` 内生成，构建工具保存在 `.cache/`；它们均不提交到 Git。

输出为 `build/overtime-notes-1.1.0-development.apk`。该安装包使用你自己的开发签名，不能覆盖安装官方签名版本。若需要切换签名，请先导出备份。

发布构建使用 `python3 build.py --release`，并从安全环境设置 `OVERTIME_KEYSTORE`、`OVERTIME_KEY_ALIAS`、`OVERTIME_KEYSTORE_PASSWORD`；私钥口令与密钥库口令不同时，另设 `OVERTIME_KEY_PASSWORD`。口令不会打印或写入命令行参数。正式更新必须保持包名和原发布签名，并递增 versionCode。

原发布签名私钥与口令未包含在公开仓库中。请勿提交私人源码归档、signing目录、密钥、个人加班数据库或备份。

## 验证

- tests/i18n.test.cjs：翻译完整性、即时切换、重载后语言保留、旧记录兼容、中英文小屏布局和英文错误提示测试。
- tests/LocaleTextTest.java：原生翻译、默认语言选择、旧类型映射、表头和导入结果文本测试。
- tests/core.test.js：前端计算、非法输入、重叠、跨月归属和统计测试。
- tests/TimeMathTest.java：原生计算与日期验证测试。
- tests/ui.test.cjs：浏览器界面操作测试，使用测试数据桥接层；需要另装Playwright（浏览器自动化测试工具），并调整脚本中本地浏览器路径。
- 正式安装包已使用发布签名，debuggable=false，不申请任何系统权限。

详细历史检查与限制见 [验收记录](docs/VALIDATION.zh-CN.md)。尚未覆盖全部品牌、Android版本和厂商文件管理器。

## 运行测试

```sh
npm ci
npm test
npx playwright install --with-deps chromium
npm run test:ui
```

浏览器测试可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已安装的浏览器。界面测试使用模拟的本地数据桥接层，不能替代安卓真机持久化验证。
